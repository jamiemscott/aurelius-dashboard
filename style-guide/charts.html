Style Guide

Charts

Chart layout and chrome classes defined in modules/charts.css. These classes handle the card structure, header, legend, tooltip, range pills, and axis labels. The SVG chart content itself is generated dynamically (OutSystems or JavaScript) — these classes style the surrounding shell, not the chart paths.

Chart Header

A flex row with a title/subtitle on the left and range pills or action buttons on the right. Sits above the chart SVG container. Use .chart-header + .chart-title + .chart-subtitle on the left, and .range-pills + .range-pill on the right.

Donut Chart with Legend

Used for asset allocation and sector breakdown displays. The .donut-wrap aligns the SVG donut (.donut-svg) side-by-side with a .legend. The centred chart card variant (.chart-card) stacks them vertically for narrower contexts.

Chart Tooltip

An absolutely positioned card that appears on hover/focus over a chart data point. The .chart-container must be position: relative (already set). The tooltip has display: none by default — On interaction, JavaScript sets its position through custom properties and toggles a state class, as .bm-tooltip does with --tip-x, --tip-y and .is-visible. pointer-events: none ensures the tooltip never captures mouse events.

OutSystems SVG Note

OutSystems InlineSVG strips class and id from the SVG element. Target by structural selector instead:

/* Local prototype (class preserved) */
.chart-svg { display: block; width: 100% !important; }

/* OutSystems (class/id stripped) */
.chart-container svg { display: block; height: auto; width: 100% !important; }

Accessibility Notes

SVG charts must include an aria-label describing the chart's purpose and key data. Tooltips must be accessible via keyboard (mouse-over data points should also respond to focus). Range pills must be buttons (role="button" or <button>) with clear active state. Legend items use colour + text — never colour alone (WCAG 1.4.1).
