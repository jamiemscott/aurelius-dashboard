Style Guide

User Menu

The topbar avatar button and its dropdown menu popover. Defined in modules/user-menu.css. Uses the native Popover API (prototype) or .is-open class (OutSystems). Width 264px, anchored to the top-right corner.

Avatar Button

A <button class="avatar"> in the topbar right zone. On hover, a gold ring appears via box-shadow. This is the popover trigger — it should have popovertarget="user-menu" or an OutSystems click handler.

Menu Panel (.user-menu)

The dropdown panel. Closed state: opacity:0; scale(0.95); pointer-events:none. Open state: opacity:1; scale(1) via :popover-open or .is-open. Uses transform-origin: top right so it scales from the avatar. Sections are separated by .um-divider. Danger items use .um-item--danger.

2FA Status Pill (.um-2fa-pill)

A small inline badge on the Security menu item. Two variants: .um-2fa-pill--on (green, 2FA enabled) and .um-2fa-pill--off (red, 2FA disabled). This gives at-a-glance security status without navigating to the security page.

Accessibility Notes

The menu panel uses role="menu" with role="menuitem" on each interactive item. Avatar trigger has aria-label="Open user menu" and aria-expanded toggled by JS. The native Popover API handles focus management; on OutSystems, manually move focus to the first menu item on open and return focus to the avatar on close. Escape must close the menu. Arrow keys should navigate between items (ARIA APG menu pattern).
