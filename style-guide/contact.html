Style Guide

Contact Form

The contact page component system — message form, segmented control, character counter, loading overlay, and success state. Defined in modules/contact.css. All form elements share tokens with the Details page input system.

Segmented Control (.contact-seg)

A pill-style tab row for switching contact method or message type. Active segment uses .is-active which applies the gold background. Only one segment should be active at a time — update via JavaScript.

<div class="contact-seg" role="tablist" aria-label="Contact method">
  <button class="contact-seg-btn is-active" role="tab" aria-selected="true">
    Send Message
  </button>
  <button class="contact-seg-btn" role="tab" aria-selected="false">
    Request Call
  </button>
  <button class="contact-seg-btn" role="tab" aria-selected="false">
    Book Meeting
  </button>
</div>

Message Textarea (.contact-textarea)

Full-width textarea with border-input styling for WCAG 1.4.11 compliance. On focus, a gold ring replaces the grey border. Character counter sits below using .contact-char-count. The lock note (.contact-lock-note) appears beneath the form to reassure users about encryption.

0 / 1000
Messages are encrypted end-to-end · FCA regulated 
<div class="contact-form-wrap">
  <label for="message">Your message</label>
  <textarea class="contact-textarea" id="message" rows="5"
    placeholder="Describe your question…" maxlength="1000"></textarea>
  <div class="contact-char-count" aria-live="polite">0 / 1000</div>
  <div class="contact-lock-note">
    <!-- lock icon --> Messages are encrypted end-to-end
  </div>
</div>

Sending Overlay (.contact-form-overlay)

When the user submits the form, a frosted-glass overlay appears over the form with a spinner. The overlay uses backdrop-filter: blur(6px) and sits position: absolute inside .contact-form-wrap.

Sending…

Success State

After successful send, the form is replaced by a confirmation panel with a circular check icon (.contact-sent-icon), a serif heading (.contact-sent-title), a reference number chip (.contact-ref), and an explanatory note (.contact-sent-note).

Do & Don't

Do

Use aria-live="polite" on .contact-char-count so screen reader users hear updates as they type.

Don't

Don't disable the submit button during sending — use the overlay instead. Disabling the button removes it from the accessibility tree and causes confusion.

Accessibility Notes

Segmented control uses role="tablist" with role="tab" buttons and aria-selected. Textarea must have a visible <label> — do not rely on placeholder alone (WCAG 1.3.5). Character counter uses aria-live="polite". The sending overlay must announce its state: add role="status" and aria-label="Sending your message". The success state should move focus to the confirmation heading.
