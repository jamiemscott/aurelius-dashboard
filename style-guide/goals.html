Style Guide

Goals

The My Goals page component system — hero, goal cards, progress rings, adjust panels, and the add-goal drawer. Defined in modules/goals.css. Goals are full-page width with .shell--no-sidebar layout. The design language is open and motivational: large serif headings, gold accents, and progress rings that animate on mount.

Goal Card (.gl-card)

The primary goal display unit. Each card shows a CSS conic-gradient progress ring with an emoji and percentage overlay, a name, saved/target amounts, monthly contribution, and a status badge. Cards are arranged in a responsive auto-fill grid (.gl-grid). Each card has a 3px top colour accent from --gl-color.

CSS Progress Ring

The ring is a pure CSS conic-gradient — no SVG, no JavaScript. The --gl-pct custom property is registered via @property with syntax: '<number>', making it animatable. Set it on the element as an inline style — the ring fills from 0 to the target value on mount.

The --gl-color property sets both the ring fill colour and the card's top accent. Pass any valid CSS colour — the goals system uses status-appropriate colours (green for savings, gold for default, etc.).

Add Goal Card (.gl-add-card)

A dashed-border placeholder card that sits at the end of the goal grid. On hover, the dashed border becomes solid gold and the icon background fills. Opens the .gl-drawer to create a new goal.

<button class="gl-add-card" popovertarget="add-goal-drawer">
  <div class="gl-add-icon">
    <!-- plus icon SVG -->
  </div>
  <div class="gl-add-label">New Goal</div>

</button>

Accessibility Notes

Progress rings are purely visual — always include a text fallback via the .gl-ring-pct percentage inside the ring. Goal names use <h3> inside the grid (grid is inside a <main> with an <h1> page title). The "Adjust" interaction must be accessible via keyboard. Status badges use colour + text — WCAG 1.4.1. Reduced-motion: the ring transition is wrapped in @media (prefers-reduced-motion: no-preference) — at rest the ring still renders at its final value, just without the animation.
