Style Guide

Brand

The Aurelius wordmark and brand mark component. Defined in modules/brand.css. Used in the sidebar header and page footers. The brand mark is a pure CSS element — no image file — making it instantly theme-responsive and sharp at any resolution. Logo and icon files are on Resources.

Full Wordmark (.brand)

A flex row combining .brand-mark (the logomark) and .brand-text (name + sub-line). Default size: mark is 34×34px with 8px radius, name is --fs-2xl (17px) in DM Serif Display, sub-line is --fs-xs (10px) uppercase with widest tracking.

Brand Mark (.brand-mark)

A 34×34px tile with border-radius: 8px and a 1.5px --gold-text outline. The Aurelius "A" monogram is painted by a ::before pseudo-element using the --brand-monogram CSS mask, filled with currentColor (--gold-text) — gold in dark mode, AA amber in light mode. The "A" text inside the element is a no-CSS fallback, hidden with font-size: 0.

34×34px (default)
48×48px (scaled)

The monogram is inlined in CSS as a data-URI mask (--brand-monogram in theme/brand.css), so there's no image request and the glyph is always sharp and theme-aware. Scaling: adjust width, height and border-radius proportionally — the glyph scales with the tile. The standalone source is src/images/brand/aurelius-monogram.svg (uses currentColor); keep it and the token in sync.

Footer Context Override

When the brand is used inside a footer, modules/brand.css applies context-specific overrides via a footer descendant selector. The sub-line colour shifts to --text-3 and the gap/layout is adjusted for a horizontal footer layout.

Do & Don't

Do

Use the CSS brand mark consistently across all pages. The mark-only variant (no wordmark) is suitable at widths ≤900px when text space is unavailable.

Don't

Don't replace .brand-mark with an <img> or a hard-coded colour SVG — it loses theme colours. Use the mask-based mark (or the currentColor source SVG) so the monogram follows the theme.

Accessibility Notes

The brand mark letter "A" is aria-hidden="true" — it is decorative. The visible "Aurelius" text in .brand-name serves as the accessible label. When the brand is wrapped in a link (e.g. to the homepage), add aria-label="Aurelius — go to homepage" on the anchor. The gold gradient on near-black text achieves a contrast ratio of approximately 8:1, meeting WCAG AA and AAA.
