Style Guide

Help Centre

All components for the Help Centre page — search hero, category cards, FAQ accordion, and the contact strip. Defined in modules/help.css. The search uses CSS :focus-within for the gold ring, and a client-side search highlights matches with mark.hs-hl.

Search Hero (.hs-search-hero)

A full-width gradient banner with a centred pill search bar. The search wrap (.hs-search-wrap) gains a gold ring on :focus-within. The clear button (.hs-search-clear) is hidden until the input has a value.

Category Cards (.hs-cat-card)

A 3-column grid of clickable category cards. On hover, the card lifts with a shadow. The active category (.is-active) receives a gold border and gold icon. A count badge shows the number of articles in each category.

FAQ Accordion (.hs-faq-item)

A pure CSS accordion using max-height transition. The question row (.hs-faq-q) contains a chevron (.hs-faq-chevron) that rotates 180° when the item is open. The answer (.hs-faq-a) transitions from max-height: 0 to 600px. Add .is-open via JavaScript — no CSS-only trick to avoid input element dependencies.

Navigate to My Investments and click "Add Investment". You can search for funds, filter by asset class, and review the fund factsheet before adding. The minimum investment is £500 per fund.

Search Highlight (mark.hs-hl)

When a search query matches text in an FAQ answer or article, wrap matching substrings in <mark class="hs-hl">. The native <mark> element has built-in semantics for screen readers. Styled with a gold tinted background.

Contact Strip (.hs-contact-strip)

A 3-column grid at the bottom of the Help page for "Still need help?" contact options. Each card (.hs-contact-card) shows an icon, heading, and description. The CTA card uses .hs-contact-cta — a layout-only modifier that stretches to column height and centres its content.

Accessibility Notes

FAQ accordion: question buttons need aria-expanded (true/false) and aria-controls pointing to the answer panel ID. Answer panel needs role="region" and aria-labelledby pointing to the question. Search input: use type="search" (gives browser clear button for free) plus aria-label. The <mark> element is natively announced by screen readers as "highlight" — no extra ARIA needed. Category cards are <button> elements, not <div>.
