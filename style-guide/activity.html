Style Guide

Activity Feed

A vertical list of transaction events — buys, sells, and dividends. Defined in modules/activity.css. Used inside card components on the portfolio overview and statement pages. Each item consists of a coloured icon chip, a body with title and subtitle, an optional amount, and a timestamp.

Anatomy & Variants

Three icon states exist: .is-buy (green), .is-sell (red), .is-div (gold/dividend). Amount uses .is-positive and .is-negative for semantic colour.

Do & Don't

Do

Always use is-positive / is-negative on amounts. Green for money received, red for money paid out — consistent with financial convention.

Don't

Don't use the activity icon classes (is-buy, is-sell, is-div) outside of .activity-icon elements — they set background and colour together and will produce unexpected results elsewhere.

Accessibility Notes

Icons are decorative (aria-hidden="true") — the activity title conveys the transaction type in text. Positive/negative amounts use colour alone for emphasis; screen readers still read the full amount string including the sign character (+ or −). Wrap the feed in a role="feed" region if it can be dynamically updated to support live regions.
