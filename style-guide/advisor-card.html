Style Guide

Advisor Card

The sidebar adviser introduction card and its contact button modifier. Defined in modules/advisor-card.css. The card appears in the left sidebar (below the nav) and gives the user quick access to their assigned wealth manager. The .contact-btn modifier reduces button size to fit the narrow sidebar context.

Anatomy (.advisor-card)

A flex column card with gold-dim background, gold-glow border, --radius-item corners, and 2px horizontal margin to prevent clipping. Contains: a badge label (.advisor-label), the adviser's name (.advisor-name), contact details (.advisor-contact), and a "Message Adviser" CTA button using the .contact-btn modifier.

.contact-btn Modifier

A size-reduction modifier applied on top of .btn-primary or .btn-secondary for sidebar-constrained contexts. Reduces font size to --fs-md (12px) and padding to 7px 12px. Also adds margin-block-start: 4px to create breathing room from the adviser contact details above it.

Do & Don't

Do

Always use .contact-btn alongside a base button class — it only overrides size, not colours or states.

Don't

Don't use .contact-btn outside of narrow sidebar or card contexts — the reduced size reduces tap target size below the 44×44px WCAG 2.5.5 threshold at full viewport widths.

Accessibility Notes

The adviser card is a landmark region — wrap it in a <section aria-label="Your adviser">. The "Message Adviser" button opens the adviser drawer: include aria-haspopup="dialog" and aria-expanded. The .contact-btn modifier reduces font size but the button element itself remains keyboard and screen reader accessible. Adviser contact details (email, phone) should be marked up as <a href="mailto:..."> and <a href="tel:..."> links.
