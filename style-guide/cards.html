Style Guide

Cards

Cards are the primary surface for grouping related content. All card variants are defined in modules/cards.css. They use --bg-card, --shadow-card, and --radius-card tokens — never redefine these inline.

Base Card — .card

The foundational surface for any grouped content. The .card class provides background, shadow, radius, and padding. Pair with .card-pad if you need consistent inner spacing without overriding the base. Use .card as a layout container — never style inner content via the card class itself.

KPI Card — .kpi-card

A compact metric tile showing a label, primary value, and an optional change indicator. Used in grids of 2–4 across the dashboard overview. The .kpi-change element takes .is-up or .is-down state classes for colour. .kpi-change-period provides soft context text.

KPI Grid & Groups — .kpi-grid, .kpi-group

.kpi-grid is a CSS grid wrapper that spaces KPI cards evenly. .kpi-group clusters logically related KPIs within a section. Use .kpi-grid at the page level; use .kpi-group inside a card or panel to group sub-metrics.

Featured KPI Card — .kpi-card.is-featured

The hero metric tile. Use exactly once per page to highlight the most important portfolio number. The .is-featured modifier scales up the value, adds a gold accent, and gives the card extra weight. Never feature more than one KPI simultaneously.

Advisor Card

The advisor card appears in the sidebar footer — it is a fixed branding component, not a reusable card variant. The structure uses .advisor-card, .advisor-label, .advisor-name, and .advisor-contact elements. Do not use this pattern outside the sidebar footer.
