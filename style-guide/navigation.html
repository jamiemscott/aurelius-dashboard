Style Guide

Navigation

Navigation components are defined in modules/navigation.css. They cover the sidebar nav items, topbar tab buttons, icon buttons, the avatar, nav badges, and page header elements. These are shell-level components — do not re-implement them in page-level CSS.

Sidebar Nav Item — .nav-item

The primary sidebar navigation link. Contains a .nav-icon SVG and a text label. The .is-active state class marks the current section — set by sg-shell.js via the data-sg-page attribute. Never set .is-active manually in HTML — always drive it from JS.

Default state Active state (.is-active) With badge 3 
<!-- Default -->
<a class="nav-item" href="/section">
  <svg class="nav-icon" aria-hidden="true" focusable="false"
    fill="none" stroke="currentColor" stroke-width="1.7" viewBox="0 0 24 24">
    <!-- icon paths -->
  </svg>
  <span>Section Name</span>
</a>

<!-- Active — set by JS, not hardcoded -->
<a class="nav-item is-active" href="/section" aria-current="page">
  <!-- ... -->
</a>

<!-- With badge -->
<a class="nav-item" href="/section">
  <!-- icon -->
  <span>Section Name</span>
  <span class="nav-badge" aria-label="3 notifications">3</span>
</a>

Nav Badge — .nav-badge

A small numeric indicator attached to a nav item to signal unread counts or pending actions. Keep counts concise — display "99+" for values above 99. Include an aria-label on the badge with the full text (e.g. aria-label="4 pending alerts") since the visual number alone lacks context.

1Single
12Double digit
99+Maximum display 
<span class="nav-badge" aria-label="4 pending alerts">4</span>

<!-- Cap at 99+ -->
<span class="nav-badge" aria-label="More than 99 items">99+</span>

Tab Buttons — .tab-btn

Top-level navigation anchors rendered in the topbar. The active tab receives .is-active. Use <a> elements (not <button>) since they navigate to distinct pages. The active item should also receive aria-current="page".

My Overview Valuation History Asset Allocation My Investments 
<nav class="topbar-nav" aria-label="Primary">
  <a class="tab-btn" href="/overview">My Overview</a>
  <a class="tab-btn is-active" href="/valuation-history"
    aria-current="page">Valuation History</a>
  <a class="tab-btn" href="/asset-allocation">Asset Allocation</a>
</nav>

Sidebar Section Label — .sidebar-section-label

A group heading inside the sidebar nav. Rendered as an <h2> with an id that is referenced by the surrounding <div role="group" aria-labelledby>. Provides structure for screen readers and visual hierarchy for sighted users. Use all-caps treatment via CSS — do not write the text in uppercase in HTML.

Portfolio

My Overview Valuation History 
<div role="group" aria-labelledby="nav-group-label">
  <h2 id="nav-group-label" class="sidebar-section-label">Portfolio</h2>
  <nav>
    <a class="nav-item" href="/"><!-- ... --></a>
  </nav>
</div>

Page Header — .page-header

The top-of-page title bar used at the start of every main content area. Contains the page <h1> and a .header-actions slot for right-aligned controls (date filters, export buttons, etc.). The page title should always be a real <h1> for proper document outline.

My Investments

<div class="page-header">
  <h1>My Investments</h1>
  <div class="header-actions">
    <button class="btn-secondary">Export CSV</button>
    <button class="icon-btn" aria-label="Filter">
      <svg aria-hidden="true" focusable="false"><!-- icon --></svg>
    </button>
  </div>
</div>

Theme Toggle

The light/dark mode toggle lives in the topbar's .site-controls region. It uses a visually hidden checkbox with a custom .theme-toggle label. The toggle is purely a visual preference override — the system respects prefers-color-scheme by default and the toggle overrides it via a data-theme attribute on <html>.

<div class="theme-switcher">
  <input type="checkbox" role="switch" id="theme-checkbox"
    class="theme-checkbox" aria-label="Colour theme">
  <label class="theme-toggle" for="theme-checkbox" aria-hidden="true">
    <span class="theme-label-dark">Dark</span>
    <span class="theme-label-light">Light</span>
  </label>
</div>
