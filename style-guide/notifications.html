Style Guide

Notifications Panel

A right-edge slide-in panel for activity notifications — portfolio updates, adviser messages, document alerts, dividends, tax notices, and security events. Defined in modules/notifications.css. Identified by id="notif-panel" (ID-targeted CSS). Uses the native Popover API on the prototype; .is-open toggle on OutSystems.

Notification Types

Each notification item receives a data-type attribute that controls its colour palette via CSS custom property overrides. Six types are defined, each with its own --notif-color and --notif-bg.

data-type Color Meaning
portfolio Green Portfolio performance updates
adviser Gold Messages from your adviser
document Indigo New documents, statements, reports
tax Amber Tax reporting, CGT notices
security Red Login alerts, security events
dividend Sky blue Dividend payments received

Notification Items

Each .np-item has a left accent stripe (3px, from --notif-color), an icon chip (.np-icon), a content block, and an optional unread dot. Unread items receive data-unread which intensifies the accent and adds a tinted background wash.

<!-- Unread item (add data-unread) -->
<li class="np-item" data-type="portfolio" data-unread>
  <button class="np-item-btn">
    <div class="np-icon"><!-- type icon --></div>
    <div class="np-content">
      <div class="np-item-title">Portfolio up 2.4% this month</div>
      <div class="np-item-body">Your Vanguard Global Equity fund is outperforming…</div>
      <span class="np-item-time">2 hours ago</span>
    </div>
    <div class="np-unread-dot" aria-hidden="true"></div>
  </button>
</li>

<!-- Read item (no data-unread, no .np-unread-dot) -->
<li class="np-item" data-type="adviser">
  <button class="np-item-btn">
    <div class="np-icon"><!-- icon --></div>
    <div class="np-content">
      <div class="np-item-title">Message from Sarah Reynolds</div>

    </div>
  </button>
</li>

Panel Shell

The panel is a drawer, with the same header, body and close button as the adviser and add fund drawers. The bell is the media, the unread count is the subtitle, and "Mark all read" is a .drawer-action. The list sits in a .drawer-body--list, which fades at the bottom while there is more to scroll. The ids are for the script that counts unread items and marks them read.

<div id="notif-panel" class="drawer" popover role="dialog" aria-labelledby="notif-panel-title">
  <header class="drawer-header">
    <div class="drawer-header-main">
      <div class="drawer-media" aria-hidden="true"><!-- bell icon --></div>
      <div>
        <h2 class="drawer-title" id="notif-panel-title">Notifications</h2>
        <p class="drawer-subtitle" id="notif-count" aria-live="polite" aria-atomic="true">3 unread</p>
      </div>
    </div>
    <div class="drawer-actions">
      <button class="drawer-action" id="notif-mark-all">Mark all read</button>
      <button class="drawer-close" popovertarget="notif-panel"
              popovertargetaction="hide" aria-label="Close">&#x2715;</button>
    </div>
  </header>
  <div class="drawer-body drawer-body--list">
    <ul class="np-list" role="list" id="notif-list">
      <!-- np-item elements -->
    </ul>
    <div class="empty-state np-empty">
      <!-- bell icon -->
      <span>You&#x2019;re all caught up</span>
    </div>
  </div>
</div>

Empty State

The .np-empty element is shown via CSS .drawer-body:not(:has(.np-item)) — no JavaScript needed. It automatically appears when the list contains no items. This is a zero-JS empty state powered entirely by the CSS :has() selector.

Entry Animation Stagger

Each .np-item uses fade-in-up with a stagger delay from --i: animation-delay: calc(var(--i, 0) * 55ms). Set style="--i:0", style="--i:1", etc. on each item so they cascade in sequence when the panel opens.

Accessibility Notes

The panel is a role="dialog" named by its title, like every drawer. It's a popover, so it isn't modal and has no aria-modal. The unread count is the subtitle, with aria-live="polite", so screen readers announce changes. When nothing is unread, the count empties and hides, and CSS hides "Mark all read" with :not(:has([data-unread])). Dismiss buttons have descriptive aria-label attributes. Escape closes the panel.

Named parts of this component, each defined with it. On an OutSystems UI widget, add the class to the widget's Style Classes property, next to any classes it already has. Layout changes at breakpoints live in the class, so don't add extra classes per screen size.
