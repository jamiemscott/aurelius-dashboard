Style Guide

Notifications Panel

A right-edge slide-in panel for activity notifications — portfolio updates, adviser messages, document alerts, dividends, tax notices, and security events. Defined in modules/notifications.css. Identified by id="notif-panel" (ID-targeted CSS). Uses the native Popover API on the prototype; .is-open toggle on OutSystems.

Notification Types

Each notification item receives a data-type attribute that controls its colour palette via CSS custom property overrides. Six types are defined, each with its own --notif-color and --notif-bg.

data-type Color Meaning
portfolio Green Portfolio performance updates
adviser Gold Messages from your adviser
document Indigo New documents, statements, reports
tax Amber Tax reporting, CGT notices
security Red Login alerts, security events
dividend Sky blue Dividend payments received

Notification Items

Each .np-item has a left accent stripe (3px, from --notif-color), an icon chip (.np-icon), a content block, and an optional unread dot. Unread items receive data-unread which intensifies the accent and adds a tinted background wash.

<!-- Unread item (add data-unread) -->
<li class="np-item" data-type="portfolio" data-unread style="--i:0">
  <button class="np-item-btn">
    <div class="np-icon"><!-- type icon --></div>
    <div class="np-content">
      <div class="np-item-title">Portfolio up 2.4% this month</div>
      <div class="np-item-body">Your Vanguard Global Equity fund is outperforming…</div>
      <span class="np-item-time">2 hours ago</span>
    </div>
    <div class="np-unread-dot" aria-hidden="true"></div>
  </button>
</li>

<!-- Read item (no data-unread, no .np-unread-dot) -->
<li class="np-item" data-type="adviser" style="--i:1">
  <button class="np-item-btn">
    <div class="np-icon"><!-- icon --></div>
    <div class="np-content">
      <div class="np-item-title">Message from Sarah Reynolds</div>
      <span class="np-item-time">Yesterday</span>
    </div>
  </button>
</li>

Panel Shell

The outer panel uses id="notif-panel" (not a class) because its open/close animation and some state-based rules are scoped to this specific element. The header contains the title, unread count badge, a "mark all read" button, and a close button. The body uses a fade-to-transparent bottom mask to signal scrollable content.

<!-- Prototype: native Popover -->
<div id="notif-panel" popover="manual" role="dialog" aria-modal="true" aria-label="Notifications">
  <div class="np-hd">
    <div class="np-hd-left">
      <!-- bell icon -->
      <span class="np-title">Notifications</span>
      <span class="np-count" aria-live="polite">3</span>
    </div>
    <div class="np-hd-right">
      <button class="np-mark-all-btn">Mark all read</button>
      <button class="np-close" popovertarget="notif-panel"
        popovertargetaction="hide" aria-label="Close notifications">
        &times;
      </button>
    </div>
  </div>
  <div class="np-body">
    <ul class="np-list" role="list">
      <!-- np-item elements -->
    </ul>
    <div class="np-empty">
      <!-- bell icon with opacity: 0.35 -->
      All caught up — no new notifications
    </div>
  </div>
</div>

Empty State

The .np-empty element is shown via CSS :not(:has(.np-item)) — no JavaScript needed. It automatically appears when the list contains no items. This is a zero-JS empty state powered entirely by the CSS :has() selector.

Entry Animation Stagger

Each .np-item uses fade-in-up with a stagger delay from --i: animation-delay: calc(var(--i, 0) * 55ms). Set style="--i:0", style="--i:1", etc. on each item so they cascade in sequence when the panel opens.

Accessibility Notes

The panel is a role="dialog" aria-modal="true" element. The unread count badge uses aria-live="polite" so screen readers announce changes. The "mark all read" button is hidden via CSS display:none when there are no unread items (using :not(:has([data-unread]))) — no JavaScript required. Dismiss buttons have descriptive aria-label attributes. Keyboard: Escape closes the panel.
