Style Guide

Forms

Every native form element available in the Aurelius design system, alongside the custom composite patterns used in the Add Funds flow. Every input must have an associated <label>. All interactive states must be keyboard-operable. Defined in modules/forms.css and base/base.css.

Text Input — <input type="text">

The standard single-line text field. Always associate with a <label> via matching for/id. Add aria-describedby to link helper text. Never rely on placeholder as the label — it disappears on input and fails contrast requirements.

Found on your welcome letter

Enter a valid 6-digit sort code (e.g. 12-34-56)

<!-- Standard -->
<label for="name">Full name</label>
<input id="name" type="text" placeholder="e.g. Sarah Mitchell">

<!-- With helper text -->
<label for="ref">Account reference</label>
<input id="ref" type="text" aria-describedby="ref-hint">
<p id="ref-hint">Found on your welcome letter</p>

<!-- Error state -->
<input id="sort" type="text" aria-invalid="true" aria-describedby="sort-err">
<p id="sort-err" role="alert">Enter a valid 6-digit sort code</p>

<!-- Disabled -->
<input type="text" disabled value="Growth Portfolio">

Input Types

Use the most specific type attribute for each input — this gives mobile users the correct keyboard (numeric, email, phone), enables browser validation, and aids assistive technology. All types inherit the same visual styling as type="text".

<input type="email"    autocomplete="email">
<input type="tel"      autocomplete="tel">
<input type="number"   min="0" max="100000" step="500">
<input type="date"     value="2024-03-15">
<input type="password" autocomplete="current-password">
<input type="search"   role="searchbox">
<input type="url"      placeholder="https://">
<input type="time"     value="09:30">

Textarea — <textarea>

Multi-line free text input. Set an explicit rows attribute to give the field a meaningful initial height — do not rely on browser defaults. Use resize: vertical only (CSS already applies this) so users can adjust height but not break horizontal layout.

Maximum 500 characters. This information will be shared with your assigned adviser.

<label for="goals">Investment goals</label>
<textarea
  id="goals"
  rows="4"
  maxlength="500"
  aria-describedby="goals-hint"
  placeholder="Describe your long-term investment objectives…"
></textarea>
<p id="goals-hint">Maximum 500 characters.</p>

Select — <select>

Use for choosing from a predefined list of options. Always include a disabled, empty first option as a visible prompt when no value is pre-selected. For large option sets (10+), prefer a searchable combobox pattern. The multiple attribute renders a list box — size it explicitly with size.

<label for="account-type">Account type</label>
<select id="account-type">
  <option value="" disabled selected>Select account type…</option>
  <option value="isa">Stocks & Shares ISA</option>
  <option value="sipp">SIPP</option>
  <option value="gia">General Investment Account</option>
</select>

Checkboxes — <input type="checkbox">

For binary true/false choices or selecting one or more items from a set. Each checkbox must have its own associated <label>. Group related checkboxes in a <fieldset> with a <legend>. The browser handles checked/focus states — do not override with custom elements that break AT.

Notification preferences 
<fieldset>
  <legend>Notification preferences</legend>

  <div class="sg-check-row">
    <input type="checkbox" id="alerts" checked>
    <label for="alerts">
      Portfolio alerts
      <span>Notify me when value changes by more than 5%</span>
    </label>
  </div>

  <!-- Disabled -->
  <input type="checkbox" id="required" disabled>
  <label for="required">Regulatory notices (required)</label>
</fieldset>

Radio Buttons — <input type="radio">

For mutually exclusive choices where only one option can be selected. All radio buttons in a group must share the same name attribute. Always wrap in a <fieldset> + <legend> for proper screen reader grouping. Keyboard: arrow keys move between options.

Withdrawal frequency 
<fieldset>
  <legend>Withdrawal frequency</legend>

  <input type="radio" id="monthly" name="frequency" value="monthly" checked>
  <label for="monthly">Monthly</label>

  <input type="radio" id="quarterly" name="frequency" value="quarterly">
  <label for="quarterly">Quarterly</label>

  <input type="radio" id="annually" name="frequency" value="annually">
  <label for="annually">Annually</label>
</fieldset>

Toggle Switch — .switch

A checkbox styled as an on/off toggle for boolean form settings. Always add role="switch" on the <input> so screen readers announce "on" / "off" rather than "checked" / "unchecked". The .switch-track sibling is purely decorative — keep it aria-hidden="true". Defined in modules/forms.css. Not to be confused with .theme-toggle, which is a separate component that controls the global color-scheme.

Auto-rebalancing

Automatically rebalance portfolio quarterly

Dividend reinvestment

Automatically reinvest dividend income

Regulatory notices

Mandatory compliance notifications — cannot be disabled

<!-- Simplest: label wraps input + track + text -->
<label class="switch">
  <input type="checkbox" role="switch">
  <span class="switch-track" aria-hidden="true"></span>
  Enable feature
</label>

<!-- Pre-checked -->
<label class="switch">
  <input type="checkbox" role="switch" checked>
  <span class="switch-track" aria-hidden="true"></span>
  Auto-rebalancing
</label>

<!-- Disabled -->
<label class="switch">
  <input type="checkbox" role="switch" checked disabled>
  <span class="switch-track" aria-hidden="true"></span>
  Regulatory notices
</label>

<!-- Separated label (for row layouts with description text) -->
<label class="switch" for="my-switch">
  <input type="checkbox" id="my-switch" role="switch"
    aria-label="Auto-rebalancing">
  <span class="switch-track" aria-hidden="true"></span>
</label>

Range Slider — <input type="range">

For selecting a value within a defined range. Always show the current value visibly — the native <input type="range"> renders no output element. Set min, max, and step explicitly. Update aria-valuenow and aria-valuetext dynamically as the value changes.

10 years
1 year 30 years
£500
£0 £2,000 
<label for="horizon">Investment horizon</label>
<output id="horizon-val">10 years</output>
<input
  id="horizon"
  type="range"
  min="1" max="30" step="1" value="10"
  aria-valuemin="1" aria-valuemax="30"
  aria-valuenow="10" aria-valuetext="10 years"
>

File Input — <input type="file">

For document upload — statements, identification, mandates. Constrain accepted types with the accept attribute. The native input is visually hidden and triggered by a styled <label> button, but the real <input> must remain in the DOM for keyboard and AT access.

PDF, JPG or PNG · Max 10MB

<!-- Visually styled label triggers the real input -->
<label for="statement">Upload bank statement</label>
<label for="statement" class="sg-file-btn">
  Choose file or drag & drop
</label>

<!-- The real input stays accessible but visually hidden -->
<input
  id="statement"
  type="file"
  accept=".pdf,.jpg,.png"
  style="position:absolute;width:1px;height:1px;overflow:hidden;clip:rect(0,0,0,0)"
>

Fieldset & Legend

Group related form controls with <fieldset> + <legend>. This is mandatory for radio groups and checkbox groups — it tells screen readers the group name. For visual sections without a group of related inputs, use a plain <div> with a heading instead. The default browser border on <fieldset> should be reset in CSS.

Personal details
Contact preferences 
<fieldset>
  <legend>Personal details</legend>
  <label for="fname">First name</label>
  <input id="fname" type="text" autocomplete="given-name">
  <label for="lname">Last name</label>
  <input id="lname" type="text" autocomplete="family-name">
</fieldset>

<!-- Radio group — fieldset+legend is mandatory -->
<fieldset>
  <legend>Contact preference</legend>
  <input type="radio" id="email" name="contact" value="email" checked>
  <label for="email">Email</label>
</fieldset>

A horizontal step indicator for multi-stage forms. Steps take .is-active (current) or .is-complete (done). The active step gets aria-current="step". Connectors between steps use .step-connector.

Method Cards — .method-card

Selectable option cards for choosing a payment or transfer method. Built as <button> elements with aria-pressed toggling selected state. Contains an icon, label, and detail string.

<div class="method-cards">
  <button class="method-card" aria-pressed="true">
    <div class="method-card-icon" aria-hidden="true"><svg>…</svg></div>
    <div class="method-card-label">Bank Transfer</div>
    <div class="method-card-detail">2–3 business days · No fee</div>
  </button>
</div>

Amount Input & Chips

A currency-prefixed number field paired with preset value shortcuts. The .amount-prefix symbol is aria-hidden — the aria-label on the input includes the currency. Chips use aria-pressed and sync their selected state with the input value bidirectionally via JS.

£ 
<div class="amount-wrap">
  <span class="amount-prefix" aria-hidden="true">£</span>
  <input class="amount-input" type="number"
    id="amount" min="1" max="100000"
    aria-label="Amount in pounds">
</div>

<div class="amount-chips" role="group" aria-label="Preset amounts">
  <button class="amount-chip" aria-pressed="false">£500</button>
  <button class="amount-chip" aria-pressed="true">£5,000</button>
</div>

Success State — .form-success

The post-submission confirmation. Apply role="status" and aria-live="polite" so screen readers announce the outcome when it appears. Contains icon, title, message, reference badge, and action buttons.

Funds on their way

Your transfer of £5,000 to Stocks & Shares ISA has been submitted and will be processed within 2–3 business days.
