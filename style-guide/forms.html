Style Guide

Forms

Form components power the Add Funds flow and other transactional surfaces. All form primitives and composite patterns are defined in modules/forms.css. Accessibility is non-negotiable: every input must have an associated <label>, and every interactive state must be keyboard-operable.

Labels & Text Inputs

Standard label + input pairs. Labels use --fs-input-label, --fw-medium, and --text-2. Inputs use --bg-input, --shadow-inner, and --radius-item. Always associate labels via for/id — never rely on placeholder text as the label.

<label for="account-name">Account name</label>
<input id="account-name" type="text" placeholder="e.g. Stocks & Shares ISA">

<label for="sort-code">Sort code</label>

  aria-describedby="sort-code-hint">
<p id="sort-code-hint">The 6-digit sort code on your bank statement</p>

Progress Steps — .steps

A horizontal step indicator for multi-stage forms. Steps take .is-active (current step) or .is-complete (completed step). Use an aria-current="step" attribute on the active step element for accessibility. The connecting lines are rendered via .step-connector elements between each .step.

Method Cards — .method-card

Selectable option cards for choosing a payment or transfer method. Built as <button> elements for native keyboard access. Add aria-pressed="true" when selected. The card contains an icon (.method-card-icon), primary label (.method-card-label), and secondary detail (.method-card-detail).

<div class="method-cards">
  <button class="method-card" aria-pressed="true">
    <div class="method-card-icon" aria-hidden="true">
      <svg><!-- icon --></svg>
    </div>
    <div class="method-card-label">Bank Transfer</div>
    <div class="method-card-detail">2–3 business days · No fee</div>
  </button>
</div>

Amount Input — .amount-wrap

A currency-prefixed amount field. The .amount-prefix holds the currency symbol (£, $, €) and is purely presentational — the aria-label on the input should include the currency: aria-label="Amount in pounds". The numeric input uses type="number" with appropriate min/max constraints.

£ 
<div class="amount-wrap">
  <span class="amount-prefix" aria-hidden="true">£</span>
  <input
    class="amount-input"
    type="number"
    id="amount"
    min="1"
    max="100000"
    placeholder="0.00"
    aria-label="Amount in pounds"
  >
</div>

Amount Chips — .amount-chip

Preset value shortcuts that populate the amount input when clicked. Built as <button> elements with aria-pressed to indicate selection. Grouped inside .amount-chips. Sync chip selection state with the amount input value in JavaScript.

<div class="amount-chips" role="group" aria-label="Preset amounts">
  <button class="amount-chip" aria-pressed="false">£500</button>
  <button class="amount-chip" aria-pressed="false">£1,000</button>
  <button class="amount-chip" aria-pressed="true">£5,000</button>
  <button class="amount-chip" aria-pressed="false">£10,000</button>
</div>

Review Card — .review-card

A summary panel displayed before confirming a transaction. Label/value rows use .review-row, .review-row-label, and .review-row-value. The total row uses the .review-row--total modifier for visual emphasis. Wrap in a <dl> for semantic description list markup.

Checkbox Row — .form-checkbox-row

Consent and agreement checkbox used in confirmation steps. Always uses a native <input type="checkbox"> for full keyboard and AT support. The .form-checkbox-text element wraps the label copy and may contain inline links for terms.

<div class="form-checkbox-row">
  <input type="checkbox" id="terms">
  <label for="terms" class="form-checkbox-text">
    I confirm this instruction and agree to the
    <a href="/terms">Terms & Conditions</a>.
  </label>
</div>

Success State — .form-success

The post-submission confirmation screen. Contains a success icon, title, subtitle, a reference badge, timeline, and action buttons. The entire section should receive role="status" and aria-live="polite" so screen readers announce the successful outcome when it appears.
