Style Guide

Feedback Messages

OutSystems system feedback messages — OS generates this markup automatically and it cannot be modified. All styles in modules/feedback.css are pure CSS overrides targeting the OS-injected class names. Four semantic variants are supported: error, success, warning, and info. Each maps to the corresponding Aurelius status tokens.

OutSystems Markup

This is the exact HTML that OutSystems injects — we have no control over it. Every class name in the structure below is an OS-owned identifier. Our CSS must target these names directly.

<!-- OutSystems injects this — cannot be modified -->
<div id="feedbackMessageContainer" class="feedback-message-wrapper">
  <div class="feedback-message feedback-message-error"
       tabindex="0" role="alert">
    <i class="fa fa-times-circle" aria-hidden="true"></i>
    <div class="feedback-message-text">
      There was a problem. Please contact the administrator.
    </div>
  </div>
</div>

Error

Used when an action fails or a system error occurs. Uses --red and --red-dim. OS typically pairs this with the fa-times-circle icon.

✕
There was a problem. Please contact the administrator.
<div class="feedback-message feedback-message-error" role="alert">
  <i class="fa fa-times-circle" aria-hidden="true"></i>
  <div class="feedback-message-text">There was a problem. Please contact the administrator.</div>
</div>

Success

Confirms that an action completed successfully. Uses --green and --green-dim. OS typically pairs this with the fa-check-circle icon.

✓
Your changes have been saved successfully.
<div class="feedback-message feedback-message-success" role="alert">
  <i class="fa fa-check-circle" aria-hidden="true"></i>
  <div class="feedback-message-text">Your changes have been saved successfully.</div>
</div>

Warning

Alerts the user to a potential issue that requires attention but has not caused a failure. Uses --gold and --gold-dim — the natural warning hue in the Aurelius palette. OS typically pairs this with the fa-exclamation-triangle icon.

⚠
Your session will expire in 5 minutes. Please save your work.
<div class="feedback-message feedback-message-warning" role="alert">
  <i class="fa fa-exclamation-triangle" aria-hidden="true"></i>
  <div class="feedback-message-text">Your session will expire in 5 minutes. Please save your work.</div>
</div>

Info

Provides neutral informational context — no action required. Uses --gold-soft and --gold-dim. The Aurelius palette has no blue; gold-soft is the designated info hue. OS typically pairs this with the fa-info-circle icon.

ℹ
Prices shown are as at previous business day close.
<div class="feedback-message feedback-message-info" role="alert">
  <i class="fa fa-info-circle" aria-hidden="true"></i>
  <div class="feedback-message-text">Prices shown are as at previous business day close.</div>
</div>

Positioning

The .feedback-message-wrapper is rendered position: fixed, centred horizontally, and offset below the topbar. The inner .feedback-message is constrained to min(480px, calc(100vw - 32px)) and enters with a short slide-down animation. On mobile the banner fills the available width with 16px gutters on each side.

/* Wrapper — OS generates position:fixed; we reposition it */
.feedback-message-wrapper {
  left: 50%;
  max-width: min(480px, calc(100vw - 32px));
  position: fixed;
  top: calc(var(--topbar-h, 68px) + 12px);
  transform: translateX(-50%);
  z-index: var(--layer-global-instant-interaction, 20);
}

/* Entrance animation */
@keyframes feedback-slide-in {
  from { opacity: 0; transform: translateY(-8px); }
  to   { opacity: 1; transform: translateY(0);    }
}

Token Map

Each variant sets three local custom properties (--fb-color, --fb-bg, --fb-border) that feed the shared base rules. Changing a status colour at the theme level automatically propagates to these messages.

Variant class --fb-color --fb-bg --fb-border
.feedback-message-error --red --red-dim color-mix(--red 30%)
.feedback-message-success --green --green-dim color-mix(--green 30%)
.feedback-message-warning --gold --gold-dim --gold-glow
.feedback-message-info --gold-soft --gold-dim --gold-glow

OutSystems Compatibility

OS ships its own stylesheet for .feedback-message. These override patterns ensure our rules take precedence.

OS behaviour Our fix
OS positions .feedback-message-wrapper at top of viewport, obscuring topbar top: calc(var(--topbar-h) + 12px) pushes it below the topbar
OS sets its own border-radius and padding on .feedback-message !important on border-radius and padding to ensure Aurelius values win
OS injects a FontAwesome .fa icon — we cannot change the element or class Target .feedback-message .fa to set color: var(--fb-color) and correct sizing
OS may add margin via ThemeGrid or component defaults margin: 0 !important on both wrapper and message elements
