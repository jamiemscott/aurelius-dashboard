Style Guide

Footer

The site footer is a three-row component defined entirely in modules/footer.css. It is rendered inside .main at the bottom of every authenticated page. The three rows are: the link grid (.footer-upper), the regulatory + sponsor strip (.footer-regulatory), and the legal bottom bar (.footer-bottom).

Footer Structure — .site-footer

The root element is <footer class="site-footer">. It carries a top border, a margin-top: 48px gap from the page content above, and three direct children that each handle a distinct band of information.

.footer-regulatory

Sponsor Logo Strip — .footer-sponsors

Three partner logos displayed in a row with thin pipe separators: OutSystems, NTT Data, and U Impact. The OutSystems and NTT Data logos come from a single combined lockup PNG (os_logo_lockup_nttdata_color_main_hires.png, 500×45px) which is split into two separate visual logos entirely via CSS — no image editing required. Each logo is wrapped in a .footer-sponsor-logo-wrap pill that uses light-dark() to stay invisible in light mode and show a white-tinted background in dark mode, preventing the PNG white backgrounds from clashing with the dark footer.

How the lockup image is split

The combined lockup PNG is 500×45px. At the rendered height of 28px (scale factor ≈ 0.622) it displays at 311px wide. A vertical pipe divider in the image sits at roughly x=255 in original coordinates (≈159px rendered).

Each crop container clips a different horizontal slice using overflow:hidden on a fixed-width <span>. The NTT container also applies transform: translateX(-165px) to its <img> to shift the image left until only the NTT Data half is visible.

.footer-sponsor-crop--os
width: 153px
overflow: hidden
/* shows px 0–153 of the 311px image */
.footer-sponsor-crop--ntt img
width: 152px
overflow: hidden
transform: translateX(-165px)
/* shows px 165–311 of the image */

Usage Notes

Rules for using and extending the footer.

  • Placement. The footer lives inside .main, after all page content. It should be the last child of the scrolling region. Never place it inside .shell directly.
  • Sponsor logo links. The href values on OutSystems and NTT Data use real URLs. The U Impact link is currently a placeholder (#) — replace with the live URL when available.
  • Adding a sponsor logo. Add a new .footer-sponsor-link + .footer-sponsor-logo-wrap block and a .footer-sponsor-sep divider. If the logo PNG has a white background, the wrap's light-dark() pill will handle dark-mode presentation automatically. If the PNG has a transparent background, set background: transparent on that specific wrap.
  • Lockup image crop values. The OS/NTT split is tuned to the specific 500×45px source image at a rendered height of 28px. If the source image is ever replaced, recalculate: scale = 28 / naturalHeight; OS crop width = pipe x-position × scale; NTT translateX = NTT start x-position × scale.
  • CSS file. All footer styles live exclusively in modules/footer.css and are included in bundle.css. Never add footer-specific overrides to page-level stylesheets.
