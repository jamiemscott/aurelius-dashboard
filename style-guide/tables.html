Style Guide

Tables

Data tables are used throughout the dashboard to display investment holdings, transactions, and performance data. Table styles are defined in modules/tables.css. Always wrap tables in .table-wrap to enable horizontal scrolling on small viewports.

Base Table

The standard table pattern. Wrap in .table-wrap for responsive overflow. Always include a <caption> or aria-label on the <table> element for screen readers. Header cells use <th scope="col">. Column type classes (.td-name, .td-type, etc.) control alignment and emphasis.

Column Type Classes

Semantic column classes control typography weight, colour, and alignment for different data types. Apply to both <th> and its corresponding <td> cells for consistent column presentation.

Class Purpose Example
.td-name Primary identifier — asset name, instrument name Vanguard FTSE Global All Cap
.td-type Category label — fund type, asset class Investment Trust
.td-secondary Supplementary data — weight, allocation %, period 22.1%
.td-change.is-up Positive movement indicator +12.4%
.td-change.is-down Negative movement indicator −3.1% 
<td class="td-name">Asset name</td>          <!-- primary label, --text-1 -->
<td class="td-type">Fund</td>               <!-- category badge style -->
<td class="td-secondary">22.1%</td>          <!-- muted, --text-2 -->
<td class="td-change is-up">+4.2%</td>      <!-- green, --green -->
<td class="td-change is-down">−1.4%</td>   <!-- red, --red -->

Sparkline Column — .sparkline

A minimal inline chart column for showing a holding's trend over time. The .sparkline cell contains an inline SVG. Keep sparklines simple — 2px stroke, no axes, no labels. The SVG must include a descriptive <title> for assistive technology.

Accessibility Notes

Financial data tables must be fully accessible. The rules below are non-negotiable in the Aurelius codebase.

  • All <table> elements must have an aria-label or visible <caption>
  • Header cells must use <th scope="col"> or <th scope="row">
  • Numeric values should use font-variant-numeric: tabular-nums for alignment
  • Change direction must not rely on colour alone — use +/− symbols or an arrow icon alongside the .is-up / .is-down class
  • Currency and percentage values should be written for screen readers: "£284,500" not "284500"
  • Wrap all tables in .table-wrap for horizontal scroll at small viewports
<!-- Required: label, scope, sign prefix on change values -->
<table aria-label="Investment holdings">
  <thead>
    <tr>
      <th scope="col">Holding</th>
      <th scope="col" style="text-align:right">1Y Change</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Vanguard FTSE Global All Cap</td>
      <!-- + prefix for screen readers; .is-up for colour -->
      <td class="td-change is-up" style="text-align:right">+4.2%</td>
    </tr>
  </tbody>
</table>
