Style Guide

Typography

Every text element available in the Aurelius design system — headings, body copy, inline elements, lists, blockquotes, code, and links. All type sizes, weights, and spacing use tokens from theme/typography.css. The primary typeface is DM Sans; DM Serif Display is for editorial display moments only.

Heading Hierarchy — h1 to h6

Headings establish document structure and must follow a logical descending order — never skip levels for visual effect. Use CSS to change appearance; always choose the heading level that reflects the content hierarchy. All headings inherit --fw-semibold by default.

Serif Display — DM Serif Display

DM Serif Display is reserved for large editorial moments — onboarding titles, hero statements, and decorative headlines. Apply via font-family: var(--font-serif). Use at most once per screen. Never apply to body copy, labels, or data values.

Body Copy

Paragraph text uses --fs-body with --lh-relaxed for comfortable reading. Secondary body at --fs-body-sm suits supporting copy and card descriptions. Long-form content should never exceed ~65ch in line length — use max-width to constrain.

Body — --fs-body

Your portfolio has grown by 12.4% over the past twelve months, outperforming the FTSE 100 benchmark by 2.1 percentage points. The primary driver has been your global equity allocation, which returned 18.2% during the period — supported by strong performance in US technology and emerging market holdings.

Body small — --fs-body-sm

Capital at risk. Past performance is not a reliable indicator of future results. The value of investments and the income from them can fall as well as rise. You may get back less than you invest.

Inline Text Elements

Semantic inline elements for emphasis, importance, annotation, and decoration. Always use the semantically correct element — e.g. <strong> for importance, <em> for stress emphasis. Never use <b> or <i> as style-only substitutes.

This is strong importance — use for critical values, warnings, or key facts. This is stress emphasis — use for a change in meaning or tone. This text contains a hyperlink to another section which inherits the brand colour. Here is a inline code snippet for technical references. Use highlighted text sparingly for search result matches. The FCA abbreviation element includes a tooltip via title.

Use small text for legal copy and fine print. Numeric data uses tabular-nums for column alignment. Strikethrough £1,200.00 shows removed values; £1,350.00 shows replacements. 

<strong>Important value or fact</strong>
<em>Stressed or nuanced phrase</em>
<a href="/path">Link text</a>
<code>inline-code-snippet</code>
<mark>Highlighted match</mark>
<abbr title="Financial Conduct Authority">FCA</abbr>
<small>Legal / fine print</small>
<del>Removed value</del>
<ins>Replacement value</ins>
<span style="font-variant-numeric:tabular-nums">£1,284,500</span>

Links

Links use var(--gold-text) to ensure they are distinguishable and accessible on both light and dark surfaces. Underlines should be visible at rest — use text-underline-offset: 3px for breathing room. Never remove underlines from body-copy links. External links should include target="_blank" with rel="noopener noreferrer".

Body link — in running text

View your full transaction history or download your annual statement for a complete breakdown of activity during the period.

Unordered Lists — <ul>

Use for items without a meaningful order — feature lists, benefit summaries, navigation links. Default browser bullets are styled via the global base CSS. Nested lists are supported up to two levels deep. Avoid more than ~7 items; consider grouping or a table instead.

Ordered Lists — <ol>

Use when sequence matters — steps in a process, ranked items, numbered instructions. The counter is rendered by the browser. Use start and reversed attributes when the numbering should not begin at 1.

  1. Select a funding source from your linked accounts
  2. Enter the amount you wish to transfer
  3. Review the transaction summary and applicable fees
  4. Confirm your identity with two-factor authentication
  5. Funds are credited within 2–3 business days
<ol>

</ol>

Description Lists — <dl>

The semantically correct element for key/value pairs — transaction summaries, metadata panels, glossary entries. The .review-row pattern in the forms module builds on <dl> structure. Use <dt> for the term/label and <dd> for the value.

Blockquote

Used for attributed quotations — adviser commentary, market outlooks, client testimonials. Always include a <cite> element for attribution. The gold left border visually anchors the quote to the brand. Keep quotes concise — two to three sentences maximum.

"Despite ongoing volatility in global markets, your portfolio's diversification strategy has provided meaningful downside protection while still participating in the equity market's recovery. The long-term positioning remains well aligned with your stated objectives."

— Sarah Mitchell, Portfolio Adviser · Q1 2024 Review 
<blockquote>
  <p>"Your portfolio's diversification strategy has provided
    meaningful downside protection..."</p>
  <cite>— Sarah Mitchell, Portfolio Adviser</cite>
</blockquote>

Code & Preformatted Text

<code> is for inline technical references — class names, tokens, API parameters. <pre><code> is for multi-line blocks (used throughout this style guide). <kbd> represents keyboard input. All use ui-monospace as the font stack — no additional fonts needed.

Inline code

Apply --gold-text for accessible brand colour on any surface, and .kpi-card.is-featured for the hero metric tile.

Type Scale Tokens

Font sizes as --fs-* tokens. Always use these — never raw px or rem. The scale includes both numeric steps and semantic aliases tied to specific UI roles.

Font Weights

Four weight tokens. Use --fw-regular for body, --fw-medium for labels and nav, --fw-semibold for headings and data values. --fw-bold is available for strong emphasis but use sparingly to preserve its impact.

--fw-regularAurelius Wealth Management — 400
--fw-mediumAurelius Wealth Management — 500
--fw-semiboldAurelius Wealth Management — 600
--fw-boldAurelius Wealth Management — 700
