Style Guide

Typography

All type sizes, weights, line heights, and letter-spacing values live in theme/typography.css as custom properties. The primary typeface is DM Sans for UI copy and DM Serif Display for editorial headlines. Always use the semantic token names — never hardcoded px or rem values.

Type Scale

Font sizes expressed as --fs-* tokens. The scale is defined in clamp() expressions where appropriate so text breathes across viewport widths. Use these tokens — never raw px or rem.

DM Sans — Primary Typeface

DM Sans is used for all UI copy: navigation, body text, labels, buttons, and data values. It is loaded via Google Fonts with a variable font axis range of 9–40 optical sizes. Available weights: 300 (light), 400 (regular), 500 (medium), 600 (semibold).

font-family: 'DM Sans', sans-serif;   /* always quote variable fonts */
font-weight: var(--fw-regular);       /* 400 */
font-weight: var(--fw-medium);        /* 500 */
font-weight: var(--fw-semibold);      /* 600 */
font-weight: var(--fw-bold);          /* 700 — sparingly */

DM Serif Display — Editorial Typeface

DM Serif Display is reserved for large editorial or hero contexts — onboarding titles, marketing headlines, and decorative display moments. Never use it for body copy or UI chrome. Apply with care: one instance per screen at most.

Font Weights

Four weight tokens cover all UI needs. Prefer --fw-regular for body and --fw-medium for labels. Use --fw-semibold for headings and data values. --fw-bold is available for emphasis but use sparingly.

--fw-regular (400) Portfolio value at a glance
--fw-medium (500) Portfolio value at a glance
--fw-semibold (600) Portfolio value at a glance
--fw-bold (700) Portfolio value at a glance 
font-weight: var(--fw-regular);    /* body copy, descriptions */
font-weight: var(--fw-medium);     /* labels, nav items, captions */
font-weight: var(--fw-semibold);   /* headings, card titles, KPI values */
font-weight: var(--fw-bold);       /* emphasis, strong — use sparingly */

Line Heights

Six line-height tokens from tight display to loose reading. --lh-none (1) is for single-line numeric data. --lh-normal (1.5) is the default. --lh-relaxed improves readability for longer paragraphs.

line-height: var(--lh-loose);     /* list items with room to breathe */

Letter Spacing

Tracking tokens for display, heading, label, and monospace contexts. --ls-widest is used exclusively for all-caps labels and section kickers. Never apply wide tracking to body copy.

--ls-snugPortfolio Value
--ls-normalPortfolio Value
--ls-widePortfolio Value
--ls-widerSection Label
--ls-widestStyle Guide
--ls-headingMy Investments
--ls-displayAurelius
letter-spacing: var(--ls-snug);   /* tighten display sizes slightly */
letter-spacing: var(--ls-normal); /* body copy default */
letter-spacing: var(--ls-heading);/* section headings */
letter-spacing: var(--ls-display);/* large serif display titles */
letter-spacing: var(--ls-wider);  /* ALL-CAPS labels, eyebrows */
letter-spacing: var(--ls-widest); /* page kickers, badges — caps only */

Text Colours

Three semantic text tokens establish a clear visual hierarchy. Never use raw hex for text — always use these tokens to ensure both light and dark modes remain accessible.

--text-1 — Primary heading and data values. Highest contrast.

--text-2 — Body copy, descriptions, and secondary labels.

--text-3 — Captions, helper text, timestamps, and metadata.

--gold-text — Brand-coloured text, accessible on both surfaces.

color: var(--text-1);      /* headings, data, primary emphasis */
color: var(--text-2);      /* body copy, card content */
color: var(--text-3);      /* captions, helper, timestamps */
color: var(--gold-text);   /* brand accent text — AA compliant */
