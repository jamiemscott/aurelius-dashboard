Style Guide

Announce Bar

A full-width notification strip that sits above the .shell grid. Used for system announcements, scheduled maintenance, and global alerts. Four semantic variants are supported, all driven by a single --ab-color / --ab-bg / --ab-border token set. Styles live in modules/announce-bar.css.

Warning

Use for scheduled maintenance, degraded performance, or anything that requires user attention before acting. Uses --status-warning and --status-warning-alpha.

Maintenance

Scheduled maintenance on Saturday 20 April 2026, 02:00–04:00 GMT. Some features may be temporarily unavailable.

Status page 
<div class="announce-bar announce-bar--warning" role="status">
  <div class="announce-bar__inner">
    <span class="announce-bar__icon" aria-hidden="true">
      <!-- warning SVG -->
    </span>
    <span class="announce-bar__tag">Maintenance</span>
    <p class="announce-bar__msg">
      Scheduled maintenance on <strong>Saturday 20 April 2026, 02:00–04:00 GMT</strong>.
      Some features may be temporarily unavailable.
    </p>
    <a class="announce-bar__action" href="#">Status page</a>
    <button class="announce-bar__dismiss" aria-label="Dismiss announcement"
            data-dismiss-bar>
      <!-- × SVG -->
    </button>
  </div>
</div>

Error

Active incidents or outages that are currently affecting users. Use sparingly — only for critical system-level problems. Uses --status-error and --status-error-alpha.

Anatomy

All inner elements are optional except .announce-bar__msg. The .announce-bar__dismiss button should be omitted on active error incidents where you don't want users to hide the notice.

<div class="announce-bar announce-bar--{variant}"
     role="status|alert">           <!-- status = polite, alert = assertive -->

  <div class="announce-bar__inner">

    <span class="announce-bar__icon" aria-hidden="true"> <!-- optional -->
      <svg>...</svg>
    </span>

    <span class="announce-bar__tag">Label</span>       <!-- optional -->

    <p class="announce-bar__msg">                      <!-- required -->
      Message text. Links and <strong> inline.
    </p>

    <a class="announce-bar__action" href="#">           <!-- optional -->
      CTA text
    </a>

    <button class="announce-bar__dismiss"               <!-- optional -->
            aria-label="Dismiss announcement"
            data-dismiss-bar>
      <!-- × SVG -->
    </button>

  </div>
</div>

Dismiss Behaviour

Buttons with data-dismiss-bar are wired by a small inline script or by the application JS. The pattern below sets hidden on the parent .announce-bar and persists the dismissed state to localStorage so it stays hidden on next page load.

<!-- Add a data-bar-id to support per-bar localStorage keys -->
<div class="announce-bar announce-bar--warning"
     id="sys-announce"
     data-bar-id="maintenance-2026-04"
     role="status">
  ...
</div>

<script>
(function () {
  document.querySelectorAll('[data-dismiss-bar]').forEach(function (btn) {
    var bar   = btn.closest('.announce-bar');
    var barId = bar && bar.dataset.barId;

    // Restore dismissed state on load
    if (barId && localStorage.getItem('ab-dismissed-' + barId)) {
      bar.hidden = true;
      return;
    }
    if (bar) bar.removeAttribute('hidden');

    btn.addEventListener('click', function () {
      bar.hidden = true;
      if (barId) localStorage.setItem('ab-dismissed-' + barId, '1');
    });
  });
}());
</script>

Placement & OutSystems

Place the .announce-bar before the .shell div so it sits outside and above the CSS grid. In OutSystems, bind visibility to a boolean variable driven by a Server Action that reads an announcement record from the database.

<body>

  <!-- Announce bar BEFORE shell ──────────────────────────────── -->
  <div class="announce-bar announce-bar--warning" role="status">
    ...
  </div>

  <!-- Shell grid ─────────────────────────────────────────────── -->
  <div class="shell vt-page">
    <header role="banner">...</header>
    <aside class="site-sidebar">...</aside>
    <main class="main">...</main>
  </div>

</body>
