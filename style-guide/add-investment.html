Style Guide

Add Investment

The full Add Investment wizard and Smart Search interface. Defined in modules/add-investment.css. Two entry modes: a traditional step-by-step wizard (.ai-* classes) and an AI-powered smart search (.ais-* classes). Both modes share the same confirmation step.

Step Progress Bar (.ai-steps)

A horizontal bar of labelled steps connected by lines. Each .ai-step has three states: default (hollow circle), active (.is-active — gold dot), and done (.is-done — solid gold with a tick). The connector line (.ai-step-line) uses ::after with scaleX() to fill progressively as steps complete.

Fund Selection Card (.ai-fund-card)

A clickable card for selecting a fund in step 1. Default state has --border-input border. Selected state (.is-selected) upgrades to a gold border with a gold checkmark (.ai-fund-checkmark). Fund stats are in .ai-fund-stats.

Filter Chips (.ai-chip)

Horizontal scrolling pill filters for narrowing fund results by asset class, region, or risk level. Active chip (.is-active) uses gold background and dark text.

AI Smart Search (.ais-*)

The .ais-* prefix is for the AI-powered conversational fund-finding mode. A mode toggle (.ais-mode-toggle) switches between "Browse" and "AI Search". The prompt bar (.ais-prompt-input + .ais-prompt-send) accepts natural language. A thinking animation (.ais-thinking-dots) shows while the AI responds. Results appear as .ais-result-card with a match pill (.ais-match-pill).

Confirmation Step (.ai-confirm-wrap)

The final step success state. An animated SVG check mark uses stroke-dashoffset animation — the circle draws in, then the tick draws in. The confirmation panel appears below once the animation completes.

Order Summary (.ai-order-summary)

A sticky right-column panel that appears during the Amount and Review steps. Uses position: sticky; top: calc(var(--topbar-h) + 24px) so it scrolls with the page but locks to the viewport top. Contains a .ai-review-table for the key/value breakdown and an acknowledgement checkbox row (.ai-ack-row).

Accessibility Notes

The step bar uses role="list" with aria-current="step" on the active step. Fund cards are <button> elements with aria-pressed for selection state. Filter chips use aria-pressed. The smart search prompt is a <textarea> with a visible label. The KIID acknowledgement checkbox must have an associated <label> — regulatory content must be readable, not hidden behind a tooltip. Confirmation success state must move focus to the confirmation heading.
