Style Guide

Drawers

Right-edge slide-in panels for contextual content — adviser messages, add fund, add investment. Defined in modules/drawers.css. All drawers use the CSS Popover API (native) on the prototype and a .is-open class toggle on OutSystems. All drawers share a translateX(100%) closed state and spring animation on open.

Drawer Variants

Three drawer classes exist, each with a different default width to suit their content. All share the same animation, backdrop, and inner layout system.

Class Width Used For
.adv-drawer 420px Adviser message drawer
.add-fund-drawer 520px Add Fund / top-up flow
.add-investment-drawer 480px Add Investment quick-add

Animation & Transition

All drawers use transform: translateX(100%) as the closed state. Opening applies transform: translateX(0) via the :popover-open pseudo-class or .is-open class. The spring easing (cubic-bezier(0.16, 1, 0.3, 1)) creates a snappy, decelerated entry. The @starting-style block enables the initial keyframe for the browser's native Popover animation.

The backdrop uses allow-discrete on the display and overlay properties to enable smooth show/hide transitions — required for the native Popover API backdrop to animate correctly.

OutSystems Overlay (.drawer-overlay)

The native Popover API provides its own ::backdrop. OutSystems cannot use this — instead, add a .drawer-overlay element as a DOM sibling to the drawer element. Show/hide it alongside the drawer to provide the same blurred backdrop effect.

<!-- Place these as siblings in the page body -->
<div class="adv-drawer is-open">
  <!-- drawer content -->
</div>
<div class="drawer-overlay"></div>

<!-- To close: remove .is-open from drawer; remove .drawer-overlay from DOM
     (or toggle its opacity/display) -->

Accessibility Notes

Drawers must trap focus while open — the native Popover API handles this automatically. On OutSystems, use a focus-trap library or manually move focus to the first interactive element inside the drawer on open, and return focus to the trigger on close. Include aria-modal="true" and role="dialog" on the drawer element. The close button must have aria-label="Close". Drawers must be closeable by pressing Escape.
