Style Guide

Data Display

Patterns for presenting financial data — KPI values, change indicators, progress bars, and elemental score bars. These components communicate portfolio performance clearly and must meet WCAG AA contrast requirements at all times. Never rely on colour alone to convey direction.

KPI Value & Label

The .kpi-value and .kpi-label pairing is the atomic unit of all metric display. The label sits above the value, using a smaller, muted treatment. The value uses font-variant-numeric: tabular-nums to keep digits horizontally stable as values change. Use --fs-kpi for standard values and --fs-kpi-hero for the featured metric.

Total Portfolio
£1,284,500
YTD Return
+9.2%
Cash Available
£84,200
Unrealised Gain
£204,180
<div class="kpi-label">Total Portfolio</div>
<div class="kpi-value">£1,284,500</div>

Change Indicators — .kpi-change

Directional change values. The .is-up modifier applies --green; .is-down applies --red. Always prefix positive values with + and negative values with − (minus sign, not hyphen) for screen readers. The .kpi-change-period span adds a muted context label.

1Y Performance
+12.4%
+£142,380 this year
Gilts Allocation
−3.1%
−£24,600 this month
Equity Weighting
68.4%
+2.4pp vs target
<!-- Positive change -->
<div class="kpi-change is-up">
  +£142,380 <span class="kpi-change-period">this year</span>
</div>

<!-- Negative change — use − (U+2212) not hyphen -->
<div class="kpi-change is-down">
  −£24,600 <span class="kpi-change-period">this month</span>
</div>

Progress Bar

A proportional fill bar for communicating allocation percentages or progress toward a goal. Always use a native <progress> element or a <div role="progressbar"> with aria-valuenow, aria-valuemin, and aria-valuemax. Never convey completeness with colour alone — include a visible percentage label.

UK Equities 37.4%
US Equities 24.1%
Bonds 15.8%
Cash 6.6% 
<div role="progressbar"
  aria-valuenow="37"
  aria-valuemin="0"
  aria-valuemax="100"
  aria-label="UK Equities: 37.4%"
  class="u-h-dyn u-bg-dyn u-radius-pill u-overflow-hidden" style="--dyn-h:8px;--dyn-bg:var(--progress-bg)">
  <div class="u-h-full u-w-dyn u-bg-gold u-radius-pill" style="--dyn-w:37.4%"></div>
</div>

Status Tags — Gain & Loss

Inline pill tags for gain/loss status in tables and detail views. Use --green/--green-dim for gains and --red/--red-dim for losses. Include a directional prefix (+ or −) and a textual label — never use colour alone to communicate direction.

+4.2% Gain −1.4% Loss Neutral 
<!-- Gain tag -->
<span class="u-bg-green-dim u-text-green u-py-2xs u-px-m u-radius-pill">
  +4.2% Gain
</span>

<!-- Loss tag -->
<span class="u-bg-red-dim u-text-red u-py-2xs u-px-m u-radius-pill">
  −1.4% Loss
</span>

Elemental Score Bars

Used on the onboarding results screen to display the five elemental alignment scores. Each bar uses the element's colour token for its fill and its background token for the track. The fill width is set dynamically by JS via style.width. Include aria-label on the bar with the element name and percentage.

Notification Dot — .notif-dot

A small circular indicator overlaid on a nav or action element to signal an unread notification — without a numeric count. Use when the exact number is unavailable or irrelevant. Always accompany with a visually hidden aria-label update on the parent element (e.g. "Settings, 1 new notification").

<div class="u-relative u-inline-flex">
  <button class="icon-btn" aria-label="Settings, 1 new notification">
    <svg aria-hidden="true"><!-- icon --></svg>
  </button>
  <span class="notif-dot" aria-hidden="true"></span>
</div>

Stat Chips — .card.stat-chip

A row of compact metric tiles used to surface key portfolio statistics — value, cost, gain/loss, yield, and cash. Each chip uses .card as its base (background, border, shadow, radius) with .stat-chip as a layout modifier (flex: 1, padding). Wrap chips in a .stat-row flex container. Value colour variants: .gold for primary metric, .green for gains, .red for losses.
