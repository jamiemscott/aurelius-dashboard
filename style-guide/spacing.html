Style Guide

Spacing & Radius

Spacing tokens, border-radius values, and shadow tokens that define the tactile language of the Aurelius UI. All values live in theme/colours.css as custom properties and resolve correctly across light and dark modes.

Spacing Tokens

The primary spacing unit is --pad, which acts as the base module. All padding, margin, and gap values should be multiples or fractions of this value for visual consistency. Avoid arbitrary pixel values — build from the token.

calc(var(--pad) * 0.25)Micro gap — icon to label
calc(var(--pad) * 0.5)Tight gap — inline elements
var(--pad)Base unit — card padding, list gaps
calc(var(--pad) * 1.5)Section row gaps
calc(var(--pad) * 2)Card-to-card spacing
calc(var(--pad) * 3)Section-to-section vertical rhythm
calc(var(--pad) * 4)Page-level top/bottom padding
padding: var(--pad);                    /* card inner padding */
padding: calc(var(--pad) * 0.75);       /* compact padding */
gap: calc(var(--pad) * 0.5);           /* tight flex/grid gaps */
gap: var(--pad);                        /* standard grid gaps */
margin-bottom: calc(var(--pad) * 2);   /* between sections */

Structural Dimensions

Fixed structural tokens that define the shell layout. These should only be consumed — not overridden — in module-level CSS. They exist so layout math can reference known constants.

H
--topbar-h
Top bar height
W
--sidebar-w
Sidebar width
P

Base spacing unit
/* Consumed in layout — do not redefine in modules */
height: var(--topbar-h);          /* aligns elements to the topbar */
width: var(--sidebar-w);          /* aligns elements to the sidebar */
padding-left: var(--sidebar-w);   /* offset main content area */

Border Radius

Three radius tokens build a consistent softness language. --radius-btn is pill-shaped for interactive elements. --radius-card is the standard panel rounding. --radius-item is a subtle rounding for list items and chips.

--radius-btnButtons & pills
--radius-cardCards & panels
--radius-itemList items & chips
0Table cells (no rounding)
border-radius: var(--radius-btn);    /* buttons, toggles, pills */
border-radius: var(--radius-card);   /* cards, modals, panels */
border-radius: var(--radius-item);   /* list rows, chips, tags */
border-radius: 50%;                  /* avatars, circular indicators */

Shadow Tokens

Two shadow tokens establish elevation. --shadow-card lifts floating surfaces (cards, dropdowns). --shadow-inner is used for sunken inputs and inset panels. Both resolve to appropriate levels in light and dark modes via light-dark().

Card shadow
--shadow-cardCards, panels, dropdowns
Inner shadow
--shadow-innerInputs, sunken panels
box-shadow: var(--shadow-card);    /* cards, floating panels */
box-shadow: var(--shadow-inner);   /* inputs, inset areas */
box-shadow: none;                  /* reset — e.g. table rows */

Borders & Dividers

--border defines the standard 1px rule for card edges, input outlines, and interactive state rings. --divider is lighter — use it for internal table rows, section separators, and list item dividers. Neither should appear on body-level elements (only on elevated surfaces).

border: 1px solid var(--border) — card and input outlines
border-bottom: 1px solid var(--divider) — row and section dividers
border: 1px solid var(--gold-glow) — focus/selected state borders 
border: 1px solid var(--border);        /* card edges, input outlines */
border-bottom: 1px solid var(--divider);/* table rows, list separators */
border: 1px solid var(--gold-glow);     /* focus ring, selected state */
outline: 2px solid var(--gold);         /* keyboard focus indicator */
