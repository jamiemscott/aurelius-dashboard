Style Guide

My Details

All components for the My Details / Account Settings page — field rows, editable inputs, toggle switches, session management, KYC/2FA status pills, and the investor profile card. Defined in modules/details.css.

Field Rows (.det-field-row)

The primary display unit for account data. A flex row with a fixed-width label (.det-field-label, min-width 148px) and a value column (.det-field-val). Add .status-tag status-tag--success inside the value to display a verified tick.

Status Dots (.det-status-dot)

Coloured pulsing dots for live status indicators (e.g. account standing, session activity). Three colour states: green (good), gold (pending/warning), red (problem). Each has a matching CSS glow via box-shadow.

Toggle Switch (.det-toggle)

A pure CSS toggle switch built with a checkbox + label pattern. The .det-toggle-row arranges the label text on the left and the toggle on the right. The checked state turns the track gold. Use inside .det-notif-wrap for notification preference grids.

Portfolio updates and reports

</div>

Danger Zone (.det-danger-zone)

A section for destructive account actions — close account, delete data. Uses a red-dim tinted background and a subtle red border. Danger links (.det-danger-link) are red-coloured text-only buttons.

Danger Zone
These actions are permanent and cannot be undone.

Accessibility Notes

Toggle switches must use role="switch" and aria-checked if built with divs; the checkbox+label pattern is preferred as it is natively accessible. Status dots use colour + text — never colour alone (WCAG 1.4.1). Revoke session buttons must have descriptive labels: aria-label="Revoke session: iPhone 15 Safari". Danger zone actions should use a confirmation dialog to prevent accidental activation.
