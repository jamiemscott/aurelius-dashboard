Style Guide

Theme Toggle

The dark/light mode switch — a hidden checkbox with a pill-shaped label track. Defined in modules/theme-toggle.css. For the theming system itself (tokens, light-dark(), color-scheme, @property), see the Theming page.

Anatomy

The toggle lives inside a .theme-switcher wrapper (which has display: contents, making it invisible to layout). The hidden .theme-checkbox is visually positioned off-screen with clip technique — it stays in the DOM at all viewport sizes so theme state is never lost. The label.theme-toggle is the visible pill with a sliding thumb. Dark/light labels flank it.

Dark Light 
<!-- Place this block anywhere in the topbar -->
<div class="theme-switcher">
  <span class="theme-label-dark" aria-hidden="true">Dark</span>

  <!-- The checkbox MUST persist at all viewport sizes -->
  <label class="theme-toggle" for="theme" aria-label="Switch colour theme">
    <input type="checkbox" class="theme-checkbox" id="theme">
  </label>

  <span class="theme-label-light" aria-hidden="true">Light</span>
</div>

<!-- Screen-reader live region -->
<div class="theme-live" aria-live="polite" aria-atomic="true"></div>

How the Toggle Switches Themes

The checkbox drives the entire colour system via a single CSS selector in theme/colours.css:

/* colours.css — default is dark mode */
:root { color-scheme: dark; }

/* When the checkbox is checked, switch to light */
html:has(.theme-checkbox:checked) { color-scheme: light; }

/* Every token uses light-dark() to respond automatically */
:root {
  --bg: light-dark(#F8F8FA, #0B0D10);
  --text-1: light-dark(#14161A, #F2F3F5);
}

The :has() selector means no JavaScript is needed to change theme — checking the box triggers the CSS cascade globally. The sg-shell.js script only reads the checkbox state to persist it to localStorage and update the accessible live region.

Responsive Behaviour

The toggle label and flanking text are hidden at viewports ≤1100px (icon rail mode). The .theme-checkbox input is intentionally never hidden — it must remain in the DOM to preserve the theme state via the :has() selector, even when invisible.

Breakpoint Behaviour
>1100pxToggle pill + dark/light labels fully visible in topbar
≤1100pxToggle visually hidden; checkbox stays in DOM; theme persists

Accessibility Notes

The toggle is a native <input type="checkbox">, which is natively keyboard-accessible (Space to toggle). The aria-label on the <label> reads "Switch colour theme". A visually-hidden .theme-live element with aria-live="polite" announces the new mode ("Dark mode enabled" / "Light mode enabled") via the JavaScript hook in sg-shell.js. The "Dark" and "Light" flanking labels are aria-hidden="true" since the label covers the semantics. Contrast of the thumb on the track meets WCAG 1.4.11 (UI component contrast).
