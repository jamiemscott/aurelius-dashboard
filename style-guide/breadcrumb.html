Style Guide

Breadcrumb

A lightweight horizontal path indicator that tells users where they are in the page hierarchy. Defined in modules/breadcrumb.css. Typically sits above the page title in the .page-header region or at the top of a wizard/multi-step flow. Renders at 12px — smaller than body copy — so it adds context without competing with the page heading.

Anatomy

The breadcrumb is a flex row of links and separators. The last item (.breadcrumb-current) is slightly lighter than the preceding links and is not a link — it represents the current page.

  1. My Investments
  2. /
  3. Portfolios
  4. /
  5. Add Investment
.breadcrumb — flex row, text-3, 12px
.breadcrumb-sep — opacity: 0.4
.breadcrumb-current — text-2, no link

Usage with Page Header

Place the breadcrumb inside the left column of .page-header, immediately above the .page-title. The 4px bottom margin on .breadcrumb provides the correct gap to the heading.

  1. My Investments
  2. /
  3. Add Investment

Add Investment

Select a fund and configure your contribution

  </div>

Token Reference

Token Value Purpose
--text-3 Tertiary text Default breadcrumb item colour
--text-2 Secondary text Current page label (.breadcrumb-current)
--fs-md 12px Breadcrumb font size
opacity: 0.4 — Separator (.breadcrumb-sep) dimming

Do & Don't

Do

Mark the current page with aria-current="page" and .breadcrumb-current — never make it a link.

  1. Parent
  2. /
  3. Current Page
Don't

Don't show a breadcrumb for top-level pages — it adds no navigational value when there's only one level.

  1. My Overview

Accessibility Notes

Wrap the breadcrumb in a <nav aria-label="Breadcrumb"> landmark so screen readers announce the region. Use an ordered list (<ol>) to convey hierarchy. Mark separators with aria-hidden="true" — they are decorative. Mark the current item with aria-current="page". WCAG 2.4.8 (Location) — Level AAA.
