Style Guide

Breadcrumb

A lightweight horizontal path indicator that tells users where they are in the page hierarchy. Defined in modules/breadcrumb.css. Typically sits above the page title in the .page-header region or at the top of a wizard/multi-step flow. Renders at 12px — smaller than body copy — so it adds context without competing with the page heading.

Anatomy

The breadcrumb is a <nav> landmark laid out as a flex row. It starts with the client's name, then each ancestor level, then the current page. An ancestor that has its own page is a real link (.breadcrumb-link). The last item (.breadcrumb-current) is never a link — it represents the current page.

Sumant Kumar / My Investments / Add Investment
nav.breadcrumb — flex row, text-3, 12px
.breadcrumb-link — text-2, text-1 on hover
.breadcrumb-sep — opacity: 0.4, aria-hidden
.breadcrumb-current — text-2, aria-current="page", no link

Usage with Page Header

Place the breadcrumb inside the left column of .page-header, immediately above the .page-title. The 4px bottom margin on .breadcrumb provides the correct gap to the heading. Every page in the prototype uses this exact markup.

Building it in OutSystems

An ODC Container renders a <div>, so give it role="navigation" in its Attributes. Screen readers then announce the same landmark as the prototype's <nav>, and .breadcrumb styles it the same way because the class doesn't depend on the element.

Inside the screen's page header, above the title:

  1. Add a Container. Set Style Classes to breadcrumb. In Attributes, add role = "navigation" and aria-label = "Breadcrumb".
  2. Inside it, add an Expression bound to the client's name.
  3. For each ancestor level, add a separator, then a Link with Style Classes breadcrumb-link that goes to that screen. Only link levels that have a screen of their own.
  4. For each separator, add a Container with Style Classes breadcrumb-sep, the text /, and the Attribute aria-hidden = "true".
  5. End with a Container with Style Classes breadcrumb-current, the page name, and the Attribute aria-current = "page". Don't make it a Link.

Put this in a block with the levels as inputs if more than one screen needs it. The OutSystems UI Breadcrumbs pattern is themed too (.breadcrumbs-item in osui-theme/widgets/navigation.css), but it has no landmark and uses an icon separator, so it won't match the prototype. If you use it, wrap it in a Container with the same role and aria-label.

Do & Don't

Do

Mark the current page with aria-current="page" and .breadcrumb-current — never make it a link. Link every ancestor that has its own page.

Don't

Don't use a plain <div> with no landmark, or leave the separators for screen readers to read out as "slash".

Accessibility Notes

Use <nav class="breadcrumb" aria-label="Breadcrumb"> so screen readers list it as a navigation landmark called "Breadcrumb". There is one per page, so the label keeps it distinct from the main navigation. Mark separators with aria-hidden="true" — they are decorative. Mark the current item with aria-current="page". WCAG 2.4.8 (Location) — Level AAA.
