Product icons

One set for each product, each in a black version with the wave and a plain white version. Every version comes as an SVG and PNGs from 16 to 1024 pixels. The words can’t be read below about 120 pixels, so very small sizes rely on the mark. The black file of the App and Library sets has no suffix, and nor does the white file of the others; the other version ends in -black or -white.

Presentation template

Where files live

Brand files go in src/images/brand/, and a new product gets its own folder under icons/. Presentations go in docs/presentations/. File names are lowercase with hyphens, with no spaces. Add new assets to this page too.
