Style Guide

Error Pages

Error pages share the .utility-shell split-column layout with the login page — the same dark brand panel on the left, the same themed panel on the right. The login form is replaced by an error code, heading, and recovery actions. Only the .error-page-* classes are new; all structural, brand, and footer elements are identical to login.

The 404 example lives at /error/. It is a fully standalone HTML file — no app shell, no sidebar — using the same bundle.css as the rest of the product.

Layout Architecture

Error pages reuse the .utility-shell grid and all .utility-* structural classes from login.css. The only difference is the panel body content — the .login-form is absent; instead the body contains an .error-page-code number, a .utility-heading, a .utility-sub description, and an .error-page-actions stack of recovery links.

Error Code — .error-page-code

A large italic serif number in var(--gold) that anchors the layout visually. It is marked aria-hidden="true" because the heading below it already names the error state — screen readers should not read a raw number as the page title. clamp(72px, 9vw, 112px) scales it proportionally between narrow mobile and wide desktop panels.

Accessibility Notes

  • Error code is decorative. The numeric code (.error-page-code) is marked aria-hidden="true". Screen readers should hear the <h1> heading as the page title, not a bare number.
  • Page title. Set <title> to something meaningful, e.g. "Page Not Found — Aurelius". This is what screen readers announce first and what appears in the browser tab.
  • Recovery link wording. Link text must be self-descriptive without surrounding context — "Return to dashboard" and "Contact client services" both work in isolation. Avoid "click here".
  • Focus order. Tab order follows DOM order: wordmark → theme toggle → primary action → secondary action → footer links. No focus traps.
  • Risk warning retained. The FCA investment risk warning is required on all pages accessible to retail clients — including error screens.
