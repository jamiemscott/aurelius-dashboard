Style Guide

Buttons

Two button variants cover all interactive needs in the dashboard. Buttons are defined in modules/buttons.css. Icon buttons and avatars live in modules/navigation.css. Never create custom button styles — extend from these patterns.

Primary Button

The highest-emphasis action on a page. Use for the single most important CTA — e.g. "Save Changes", "Continue", "Add Funds". Never place more than one .btn-primary in the same visible context. The gold fill communicates the brand's primary action colour.

<button class="btn-primary">Save Changes</button>

Secondary Button

A lower-emphasis alternative. Use alongside a primary button for cancel/back actions, or as the sole action when no primary CTA is needed. The outlined or muted treatment signals secondary intent without visual competition.

<button class="btn-secondary">Cancel</button>

Primary + Secondary Pair

The canonical two-button pattern: primary right, secondary left. Always position the primary action to the right so users read secondary → primary and confirm deliberately. Use a flex row with a gap of var(--pad).

<div style="display:flex;gap:var(--pad)">
  <button class="btn-secondary">Back</button>
  <button class="btn-primary">Continue</button>
</div>

Button with Icon

Add a leading or trailing SVG icon inside any button variant. Keep icons at 16×16 or 18×18. The icon should be aria-hidden="true" and focusable="false". The button's text label provides the accessible name — never rely on icon alone.

<!-- Leading icon -->
<button class="btn-primary" style="display:inline-flex;align-items:center;gap:8px">
  <svg aria-hidden="true" focusable="false" width="16" height="16"
    fill="none" stroke="currentColor" stroke-width="2" viewBox="0 0 24 24">
    <path d="M12 5v14M5 12l7 7 7-7"/>
  </svg>
  Add Funds
</button>

<!-- Trailing icon -->
<button class="btn-primary" style="display:inline-flex;align-items:center;gap:8px">
  Continue
  <svg aria-hidden="true" focusable="false" width="16" height="16"
    fill="none" stroke="currentColor" stroke-width="2" viewBox="0 0 24 24">
    <polyline points="9 18 15 12 9 6"/>
  </svg>
</button>

Disabled State

Use the HTML disabled attribute — never a class-only approach. The browser handles cursor: not-allowed, focus suppression, and AT announcements automatically. Consider adding an explanatory tooltip via aria-describedby on the disabled button to explain why the action is unavailable.

<!-- Use the disabled attribute — not a CSS class -->
<button class="btn-primary" disabled>Save Changes</button>
<button class="btn-secondary" disabled>Cancel</button>

<!-- With aria-describedby for context -->
<button class="btn-primary" disabled aria-describedby="save-hint">Save Changes</button>
<p id="save-hint" class="sr-only">Complete all required fields to enable save.</p>

Icon Button — .icon-btn

A minimal square button for toolbar actions — settings, filters, more. Always provide a descriptive aria-label since there is no visible text. Part of the navigation shell; defined in modules/navigation.css.

<button class="icon-btn" aria-label="Settings">
  <svg aria-hidden="true" focusable="false" width="18" height="18"
    fill="none" stroke="currentColor" stroke-width="1.7" viewBox="0 0 24 24">
    <!-- icon paths -->
  </svg>
</button>

Avatar Button — .avatar

A circular button displaying the user's initials. Used in the topbar for account access. The initials are the accessible label — supplement with aria-label describing the action (e.g. "Account — Sarah King"). Defined in modules/navigation.css.

<button class="avatar" aria-label="Account — Sarah King">SK</button>

AI Agent Button — .btn-ai

The entry point to the Aurelius AI agent chat. Visually distinct from .btn-primary and .btn-secondary — uses a blue→violet animated gradient to signal AI rather than a standard action. The icon is an 8-point radial node evoking intelligence. Below 1100px the text label collapses and only the icon shows, preserving header space at laptop widths. Typically rendered as an <a> linking to /chat/.

Ask Aurelius AI

AI Promotional Banner — .ai-banner

A full-width gradient card promoting the Aurelius AI agent. Sits between the page header and the KPI strip on My Overview. Shares the same blue→violet gradient as .btn-ai. Dismissable for the session via JS — on dismiss the banner hides and the .btn-ai in .header-actions is revealed. The description text (.ai-banner__text) collapses below 900px to keep the banner compact on smaller viewports.

Button visibility rule: when the banner is shown the header .btn-ai must be hidden (style="display:none"), since both serve the same purpose. They are mutually exclusive — never display both simultaneously.

Meet Aurelius AI — your personal wealth analyst

Ask plain-English questions about your portfolio, tax position, and investment performance. Instant answers, grounded in your actual data.

Try it now

<!-- .btn-ai in header-actions: hidden while banner is visible -->
<a class="btn-ai" href="/chat/" aria-label="Ask Aurelius AI" style="display:none">
  <!-- icon -->
  <span class="btn-ai-label">Ask Aurelius AI</span>

<!-- Dismiss script: toggles banner/button; persists for the session -->
<script>
(function () {
  var banner    = document.getElementById('ai-banner');
  var dismiss   = document.getElementById('ai-banner-dismiss');
  var headerBtn = document.querySelector('.header-actions .btn-ai');
  if (!banner || !dismiss) return;
  function showButton() { if (headerBtn) headerBtn.style.display = 'inline-flex'; }
  function hideButton() { if (headerBtn) headerBtn.style.display = 'none'; }
  if (sessionStorage.getItem('ai-banner-dismissed')) {
    banner.hidden = true;
    showButton();
  } else {
    hideButton();
  }
  dismiss.addEventListener('click', function () {
    banner.hidden = true;
    showButton();
    sessionStorage.setItem('ai-banner-dismissed', '1');
  });
}());
</script>

Do & Don't

Common mistakes and correct patterns for button usage in the Aurelius dashboard.

Do

One primary action per context. Clear, verb-led label.

Don't

Multiple primary buttons compete for attention and confuse users.
